# 窓口調査の手順（調査を担当するエージェント向け）

割り当てられた自治体（または国の機関）ごとに、公式の窓口連絡先を調べ、指定された JSON ファイルに書く。
書いた内容は、あとで `scripts/research-merge.mjs` が出典ページを自動で開き直し、電話番号・メールアドレス等が
本当にそのページに書かれているかを機械的に照合する。照合に通らない項目は捨てられるので、推測で埋めても意味はない。

## 調べる窓口（type）

| type | 内容 | 対象 |
|---|---|---|
| `general` | 行政代表窓口：代表電話・総合案内 | 都道府県・市区町村・国の機関・国会 |
| `feedback` | 広聴・ご意見窓口：広聴課、県民（市民）の声、知事（市長）への提言、意見・要望の受付など | 都道府県・市区町村・国の機関 |
| `assembly` | 議会事務局：議会への問い合わせ、請願・陳情の受付 | 都道府県・市区町村 |

国の機関は実際の組織に合わせる。「ご意見・ご要望」の受付窓口（フォーム等）があれば `feedback`、なければ `feedback` は `not_found`。衆議院・参議院は `general` だけ。

## 守ること

1. **公式一次資料だけ**：国の機関・自治体・議会の公式サイト（`go.jp`・`lg.jp`・`pref.〜`・`city.〜`・`town.〜`・`vill.〜` など）。
   検索エンジン・J-LIS のリンク集・Wikipedia などは「公式ページを見つける」ためだけに使い、そこに出た番号や要約は使わない。
2. 電話・メール・フォームURL・郵便番号・住所・受付時間は、**WebFetch で開いた公式ページの本文で直接確認できたものだけ**書く。
   確認できない項目は `null`。市外局番の補完、メールアドレスの組み立てなどの推測は禁止。
3. **用途を確かめる**：代表電話を広聴・議会の番号として流用しない。そのページに「その窓口の連絡先」として書かれているものだけ。
   広聴のページに電話番号が書かれていなければ、広聴の `phone` は `null`（フォームやメールだけでよい）。
4. 組織の窓口だけ。職員個人・議員個人の連絡先は扱わない。
5. `source_url` は、その連絡先が実際に書かれているページの URL（代表電話がトップページの下部にあるならトップページ）。
   1つの窓口の情報が複数ページに分かれているときは、主な情報のあるページを1つ選び、そのページにない項目は `null`。
   `form_url` だけは別ページでよい（ただし `source_url` のページからリンクされている、公式の受付ページに限る）。
6. `evidence` には、ページ本文の該当箇所を短くそのまま書き写す（例：`代表電話 011-231-4111`）。
7. ページが開けない（403・タイムアウトなど）ときは `agent_status: "fetch_failed"`、公式サイトを調べても窓口が見つからないときは
   `agent_status: "not_found"`（調べたページの URL を `source_url` に入れる）。連絡先の項目は `null` のまま。
8. 受付フォームが外部の申請サービス（e-tumo、LoGoフォーム、graffer、kintone など）にある場合は、公式ページからリンクされているものだけ。
9. 1つの自治体につき、各 type 1件まで（いちばん代表的な窓口を選ぶ）。

## 書き方

- 電話番号：半角数字とハイフン（例 `03-5321-1111`、`0120-123-456`）。内線番号は書かない（`note` に書いてもよい）。
- 郵便番号：`123-4567`。住所：ページの表記どおり（都道府県名から）。
- `department`：ページ上の正式な名前（例：`代表電話`、`総務部 広報広聴課`、`県民の声`、`議会事務局`）。
- `hours`：ページに書かれているときだけ、短く（例：`平日 8時30分〜17時15分`）。
- `note`：必要な注意だけ短く（例：`意見はフォームで受付。電話番号は掲載なし`）。なければ `null`。

## 出力ファイル（指定されたパスに Write で書く。UTF-8 の JSON）

```json
{
  "batch": "pref-01",
  "researched_at": "2026-11-01",
  "entities": [
    {
      "code": "010006",
      "name": "北海道",
      "official_site": "https://www.pref.hokkaido.lg.jp/",
      "contacts": [
        {
          "type": "general",
          "agent_status": "found",
          "department": "代表電話",
          "phone": "011-231-4111",
          "email": null,
          "form_url": null,
          "postal_code": "060-8588",
          "postal_address": "北海道札幌市中央区北3条西6丁目",
          "hours": null,
          "source_url": "https://www.pref.hokkaido.lg.jp/",
          "evidence": "〒060-8588 札幌市中央区北3条西6丁目 電話番号 011-231-4111（総合案内）",
          "note": null
        }
      ]
    }
  ]
}
```

- `code`：自治体は6けたの全国地方公共団体コード（割り当て表のとおり）、国の機関は機関ID。`name` も割り当て表のとおり。
- 各 entity の `contacts` には、その entity で調べる type をすべて入れる（見つからなくても `not_found` / `fetch_failed` で1件ずつ）。
- 書き終えたら、ファイルが正しい JSON か読み直して確かめる。

## メインへの報告（これだけを返す）

調べた数・found 件数・not_found 件数・fetch_failed 件数・書いたファイル名。ページ本文・検索結果・経過は返さない。
